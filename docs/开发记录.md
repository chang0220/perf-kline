# 开发记录（本项目唯一的状态入口）

项目名 perf-kline，App 名“性能行情”（名字暂定，可推翻）。用户 = 仓库作者。

## 状态

- 2026-11-10 建。**2026-11-10 第一版做完**：编好的 App 交付在作者本机的交付目录（位置记在本机项目总表里，不放进公开仓库）。
- 用户定的（2026-11-10，选择题回答）：做 **Mac 原生版**（不试现成的 C++ 重写版）；形态 **完整窗口 + 菜单栏小行情**。
- 用户 2026-11-10 原话“你根据预览图自己决定，然后完整做出来”，以下是**替用户代定、可推翻**的事项：
  1. 风格选 **B 石墨**；系统切到浅色外观时自动用 **C 浅色**的配色（两套共用一份布局）。理由：B 最像 Mac 原生（系统字体、中性深灰、只在选中项点琥珀色）；A 的纯黑 + 黄字在 Mac 上像在模仿老终端。
  2. **涨跌的参考点 = 10 分钟前的读数**（运行不足 10 分钟时用第一次读数）。股票的“昨收”在这里没有对应物，所以不叫“今开”，界面上写明“10分钟前”。
  3. **成交量**：每只“股票”用和它自己相关的真实计数——CPU / 各核：中断次数；内存：缺页次数；网络：收 / 发包数；磁盘：读 / 写操作次数。GPU、温度、功耗、进程数、负载没有对应计数，图上明确写“没有对应的计数”，不硬凑。
  4. “逐笔成交”的事件规则和阈值是自定的（行情软件没有可抄的标准），集中在 `Sources/KlineCore/Tape.swift` 顶部。
  5. 默认 **红涨绿跌**（国内习惯），标题栏一键切换。
  6. Bundle ID `local.perfkline`；没有做 App 图标（图标属于用户拍板的事）。
  7. 2026-11-10 用户要求开源、许可证由我定：选 **MIT**，署名 Chang Xu（和作者另一个仓库 microwatt-meter 一致）。理由：最宽松、只要求保留署名；借用的 Stats 键名表也是 MIT；没有用 GPL 的 PerfTicker 代码，不受 GPL 约束。提交作者邮箱改用 GitHub 隐私邮箱。
- **App 自身 CPU 开销（记录在案的未达标项）**：通过线事先定为“1 秒采样、窗口亮屏可见时 ≤ 3%（单核计）”，2026-11-10 20:2x 亮屏实测 **4.12% / 4.12%，没过**。窗口关掉只剩菜单栏时 0.45% / 0.64%（通过线 ≤ 1.5%，过）；不开界面只采样 0.83%。
  - 量法：截图自检模式加 `--threads --real-visibility`，用 `task_threads` + `thread_info` 按线程累计 CPU 时间（合计值和 `ps` 对得上）。早先用 `ps -M` 按行号对线程的量法不可靠（线程会生灭、行号错位），那组数据作废；熄屏时测的数据也作废（熄屏时窗口本该不画却还在画，这正是下面修掉的问题）。
  - 调用树里的大头（主线程，6 秒样本数）：图层提交重绘 84、SwiftUI 重新布局约 70、系统重算窗口拖动 / 缩放区域 40、菜单栏小行情重绘 39。都是“每秒刷新一整屏”的固有成本。
  - 已做：窗口被挡住 / 最小化 / 关掉 / 熄屏时界面不刷新（数据照常采集），熄屏 / 锁屏时菜单栏不刷新；修之前熄屏时还要 5.9%–12.8%。行视图内容不变跳过重画、菜单栏内容不变不重设（这两项效果没单独量出来）。
  - 要压到 3% 以下得换渲染方式（例如 K 线主图和小 K 线改用 CALayer 直接画），是较大改动，没在这一轮做，等用户决定要不要。
  - 另外 `ps` 子进程每 2 秒一次、每次约 26 毫秒，约合 1% 单核，算在 `ps` 进程头上。
- 2026-11-10 用户试用时崩溃一次（系统崩溃报告 PerfKline-2026-11-10-202445.ips）：在 K 线图上滚动滚轮必崩。原因是滚动范围检查用 `candles(maxCount: Int.max)` 取全部 K 线，函数里按 maxCount 预留内存，申请约 1.8×10¹⁹ 字节失败。已修（预留不超过采样数；滚动检查改用只计数的 `candleCount`），加了回归测试（撤掉修复时该测试以同样方式崩溃，确认测得到）；并用 `--scroll-test` 在真实 App 里把滚轮事件交给 K 线图交互层，缩放 3–40 和往回翻的限位（历史 28 根、屏幕 18 根 → 最多翻 10 根）都符合预期。
- **没验证过的**：键盘操作、触控板双指捏合 / 按住拖动、置顶、菜单栏下拉菜单的实际点击（需要人在屏幕前操作）。滚轮缩放和左右平移已在真实 App 里用合成事件验证过。
