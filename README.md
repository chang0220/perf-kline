# perf-kline（名字暂定，可推翻）

把 Mac 的系统占用（CPU、GPU、内存、温度、网络……）画成炒股软件那样的 K 线行情：完整窗口 + 菜单栏小行情。

- **等用户选风格**：`design/方向对比.html`（`#a` / `#b` / `#c` 切换），效果图在 `~/code/_交付/perf-kline/`：
  - A 经典行情终端（纯黑底、红色空心阳线、青色实心阴线、黄色名称、等宽数字）
  - B 石墨（中性深灰、红绿实心、苹果系统字体、琥珀色只点在选中项）
  - C 浅色（暖白底、黑色强调）
  - 三张图布局和数据完全一样，数据是固定种子模拟的示意数据。

## 灵感来源与查证（2026-11-10）

- 原版 **PerfTicker**：https://github.com/QiuSui1145/PerfTicker ，C# / Windows 专用，**GPL-3.0**。按规矩只学公开思路（指标当“个股”、K 线、主力动向、逐笔成交），**不抄代码和数值**（包括它的“营收”公式参数）。
- 跨平台重写 **perfticker-mcpp**：https://github.com/ztuqfvy/perfticker-mcpp ，C++23 + Dear ImGui，写着支持 macOS。没有选它的原因：仓库**没有许可证文件**（不能合法拿来改）、没有发布包、要装第三方 mcpp 工具链、0 星、11-03 一次性上传后没更新、没人验证过 Mac 上能跑、界面不是 Mac 原生。
- 本机（M4 Pro，macOS 27.2）不用管理员权限实测能读到：GPU 占用（`ioreg` 的 IOAccelerator “Device Utilization %”）、各进程 CPU / 内存（`ps`）。
- 苹果芯片不向普通程序公开 CPU 实时频率（perfticker-mcpp 的 README 也这么写），所以逐核只能画占用率，不画 GHz。
- 温度、功耗：**待验证**（打算查 macmon 等开源项目的做法，注意许可证）。
